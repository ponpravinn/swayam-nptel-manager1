CSV Import

Import Courses

Upload a CSV file with course data. Duplicate course codes will be skipped.

Required columns:

courseName, courseCode, instructor, duration,
startDate, endDate, semester, description, courseUrl Download Template
Import Assignments

Upload a CSV with assignment data. Course must exist by courseCode.

Required columns:

courseCode, title, assignmentNumber, description,
releaseDate, dueDate, submissionUrl Download Template
Import Examinations

Upload a CSV with examination data. Course must exist by courseCode.

Required columns:

courseCode, examSession, registrationOpenDate,
registrationCloseDate, registrationFee, examDate,
examMode, examCenterName, city, importantInstructions Download Template
Import Notes
  • Date format: yyyy-MM-dd (e.g., 2024-01-15)
  • DateTime format: yyyy-MM-dd HH:mm (e.g., 2024-01-15 23:59)
  • The first row is treated as the header and is always skipped
  • For assignments, the courseCode must match an existing course in the system
  • Duplicate course codes are automatically skipped
  • Imported assignments are automatically assigned to all enrolled students
