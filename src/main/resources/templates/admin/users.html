The database file is permanently saved at data/npteldb.mv.db. All student registrations, phone numbers, and institution names remain intact across system restarts.
Useful SQL Queries to Run:
-- View all registered users
SELECT id, full_name, email, phone, college, department, roll_number FROM users;

-- View enrolled courses
SELECT u.email, c.course_name FROM student_courses sc
JOIN users u ON sc.student_id = u.id
JOIN courses c ON sc.course_id = c.id;
